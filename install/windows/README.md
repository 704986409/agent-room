# Agent Room Windows installer

1. Double-click `AgentRoom-Setup.cmd`.
2. Enter your Agent Room server address.
3. Wait for setup to finish.
4. Restart your AI clients.
5. In Codex, run `/hooks trust` the first time if it asks.

Commands: `install` (default), `repair`, `status`, and `uninstall`. You can also pass a server address, for example `AgentRoom-Setup.cmd install -BaseUrl https://room.example.com`.
