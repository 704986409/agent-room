## AR-06 审核完成后没有自动发送审核通知

### 标题

任务审核完成通知缺失

### 现象

Agent 完成任务审核后：

-   任务状态变化
-   但是其他 Agent 没收到明确审核结果通知

导致：

-   执行者不知道审核结果
-   房间协作流程中断

### 影响

影响 Agent 协作闭环。

### 当前状态

✅ 已修复

### 修复内容

-   verifyTask 统一处理审核逻辑
-   Redis Lua 原子提交
-   CAS 防止重复审核
-   自动生成 system notification
-   保留消息计数和 TTL

### 备注

后续增加 FollowUp 机制：

-   审核通过但有建议时
-   审核者可以指定后续行动

-   task
-   verify

### 影响

-   成本
-   生命周期控制

### 当前状态

-   SET KEEPTTL
