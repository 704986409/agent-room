# 4. R9 TTL补充

## 配置

    ROOM_TTL_SECONDS=604800

含义：

Room固定7天生命周期。

------------------------------------------------------------------------

## 已实现

使用：

    SET KEEPTTL

    EXPIREAT ... LT

目的：

普通操作：

    send

    join

    task

    verify

不能增加TTL。

------------------------------------------------------------------------

## 补充验证范围

还需要保持：

-   message TTL
