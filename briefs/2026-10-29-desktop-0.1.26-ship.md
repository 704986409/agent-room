## NSIS kill behavior
`AgentRoomKillLockedProcs` runs on **PREINSTALL** and **PREUNINSTALL**:
1. `taskkill /F /IM "Agent Room.exe" /T`
2. PowerShell ×3 retries (~900ms apart): `Stop-Process` for any Win32 process whose **ExecutablePath** matches `$INSTDIR` (bundled `node.exe`, `OpenConsole.exe`, …) **or** whose **CommandLine** matches `agent-room-daemon` (system/`AGENT_ROOM_NODE` hosting the daemon)
3. Extra `Sleep 1500` so `conpty.node` / `conpty.dll` locks release before file replace

## Residual risks
- **WebView2 pop-out** still needs Windows QA (Linux WebKit only proved no data:-URL fallback).
- **MSI** does not run these NSIS hooks — prefer the NSIS `.exe` when upgrading over a live session.
- Kill-by-CommandLine `agent-room-daemon` is broad by design; unlikely to hit unrelated processes.
- Seat CLIs (cursor-agent, etc.) outside `$INSTDIR` are not killed; they do not hold `conpty.node` (the daemon node process does).
